# Super Cleaners London

This folder contains two enhanced homepage designs for Super Cleaners London.

## Pages

- [`index.html`](./index.html) — Version 1 homepage with a cinematic cleaner-video banner, floating service badges, service cards, London coverage checker, cleaning journal, team, reviews, FAQ, and contact section.
- [`home-v2.html`](./home-v2.html) — Version 2 homepage with a light editorial hero, interactive service and coverage sections, a distinct dark editorial cleaning journal, team, reviews, FAQ, and contact section.

## Shared assets

- [`css/enhancements.css`](./css/enhancements.css) — Shared responsive header and mobile navigation, modal, animations, floating effects, and interactive card styles.
- [`js/enhancements.js`](./js/enhancements.js) — Shared JavaScript for navigation, scroll effects, interactive hero badges, coverage checker, modal controls, and other page interactions.

The Version 1 hero video and several images are loaded from external hosts. The hero video is muted and loops automatically; its poster image provides a visual fallback.

## Preview

Open `index.html` or `home-v2.html` in a browser. For local development, serve this folder over HTTP so relative CSS and JavaScript assets load correctly.
